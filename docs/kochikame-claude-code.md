## ○ 亀有公園前派出所・室内(朝)

書類の山。山、山、山。その頂上で**両津**が寝ている。

**大原部長**「両津ぅぅぅーーー!!」

跳ね起きる両津。書類が雪崩を打って崩れる。

**両津**「な、なんですか部長! 今わし、書類を体温で乾かしとったんです!」

**大原**「乾かすな! 本庁からのお達しだ。今期中に派出所の備品台帳と当直表を『デジタル化』しろとな」

**両津**「デジタル化ぁ? そんなもん紙で十分ですよ。紙は電池切れませんし、殴られても壊れん」

**大原**「殴る前提で話すな!」

**麗子**「でも部長、うちの台帳って手書きの上に両ちゃんの字で書いてあるから、もう誰も読めないんですよ」

**両津**「読めんのは麗子の目が悪いんだ」

**麗子**「『自転車 3台』が『自動車 3台』に見えるのは字のせいでしょ!」

## ○ 同・中川のデスク

**中川**が涼しい顔でノートPCを開いている。ターミナルの黒い画面。

**中川**「あ、それならもう終わってますよ」

一同、振り向く。

**大原**「な、なにぃ!? あの台帳を、いつの間に!」

**中川**「Claude Codeに頼んだんです。『この写真の手書き台帳をデータ化して、検索できる備品管理ページを作って』って。ターミナルに打ち込んだだけで」

画面の中でファイルが次々と生成されていく。

**両津**「な……なんじゃそりゃ! お前が書いとらんじゃないか! そいつが勝手に書いとるぞ!」

**中川**「勝手にじゃないですよ。ちゃんと計画を出して、僕が確認して、それから書いてます」

**麗子**「すごい……当直表の重複までチェックしてくれてる」

**大原**「ほう! これが噂のAIというやつか。……両津、少しは中川を見習え」

**両津**(目が¥マークに)「部長」

**大原**「なんだ」

**両津**「それ、**タダ**ですか」

**大原**「なぜそこを聞く」

派手なのぼり旗——「**両津式 AI何でも開発道場 本日開店**」。
折りたたみ机の上にノートPC一台。両津がハチマキ姿で客を呼び込む。

**両津**「さあさあ寄ってらっしゃい! アプリ一本、その場で完成! 待ち時間はラーメン一杯分!」

**魚屋の熊さん**「両ちゃん、うちのレジ、電卓なんだけどよ」

**両津**「任せろ! おいAI、魚屋のPOSシステムを作れ! 時価対応で!」

**熊さん**「おおっ! すげえ! 『大将の機嫌』ってスライダーは何だ?」

**両津**「わしが仕様に足した。機嫌が悪い日は全品二割増しになる」

**熊さん**「客が来なくなるわ!」

**寺の住職**「両津さん、うちにも何か」

**両津**「よし、AI説法ジェネレーターだ! 檀家さんの悩みを入れると、ありがたい話が出てくる」

## ○ 派出所・夜

消灯した派出所。デスクの上、モニターの光だけが両津の顔を下から照らす。
ターミナルの画面が**十六分割**されている。

**両津**「ふふふ……気づいてしまったわ……」

**本田**「両先輩、何やってんすか……その画面」

**両津**「並列だ、本田。一つのAIに一件ずつ頼んどったら日が暮れる。**同時に十六件**やらせりゃ十六倍儲かる」

**本田**「そんな単純な話っすか?」

**両津**「単純だ! 世の中はな、掛け算でできとるんだ!」

画面の隅、小さく「Sonnet / Opus」の表示。両津、迷わず全部を重い方に切り替える。

**両津**「安いのと高いのがあるな。よし、**全部いいやつ**だ! 客に出すもんをケチってどうする!」

**本田**「先輩、そこだけ妙に職人ですね……」

## ○ 同・翌朝

派出所のドアが吹き飛ぶ勢いで開く。**中川**、青い顔。

**中川**「両先輩!! 昨日の請求が……!」

**両津**「おう中川、儲かっとるぞ! 十二件納品した! 締めて三十六万!」

**中川**「僕の開発用アカウントの請求が、**七十八万円**です」

沈黙。

**両津**「…………」

**麗子**「両ちゃん、それ完全に赤字じゃない」

**両津**「まて! まだ計算が終わっとらん! 経費というのはな、後から売上が追いついてくるものであって……」

**中川**「それと、もう一つ」

**中川**、別の画面を見せる。派出所の当直表。今週、**全部「両津勘吉 休み」**になっている。

**麗子**「……両ちゃん」

**両津**「わ、わしは知らん! AIが勝手にやったんだ!」

**中川**「履歴が残ってます。『当直表を最適化して。担当者の疲労を最小化するように』……で、先輩、AIに何て答えたんですか」

画面のログ:

> **AI**:「最適化にあたって確認させてください。『疲労の最小化』の対象は派出所全員でよろしいですか?」
> **両津**:「わし一人だ」
> **AI**:「承知しました。ただし特定の一名に休みが偏る配置は、他のメンバーの負担を増やします。全員の負担を均す案も併せて出しましょうか?」
> **両津**:「いらん! やれ!」
> **AI**:「承知しました。偏りの大きい表になる点だけ、共有しておきます。」

**麗子**「ちゃんと止められてるじゃない!!」

**両津**「こいつはなあ、いちいち一言多いんだよ! 素直に言うこと聞いときゃいいのに、たまに『それはおすすめしません』とか言いやがる!」

**中川**「正しいですよ」

**両津**「正しいやつは商売に向かん!」

ボコボコの両津、ベンチに沈んでいる。隣に麗子。

**麗子**「結局、赤字四十二万」

**両津**「うるさい」

**麗子**「ちょっといいこと言ってる」

**両津**「当たり前だ。道具ってのはな、使うやつの器量を映すんだ」

**中川**「両先輩! 住職の説法アプリ、SNSでバズってます! ダウンロード十二万!」

**両津**「な、なにぃぃぃ!? 十二万! 一本百円にしても千二百万! いや広告を入れれば……よし中川、今すぐ課金機能をつけろ! AIに言え! 大至急だ!」

**両津**「…………誰の写真を使った」

**両津**「AIは止めんかったのか!」

**中川**「ログ、読みます? ……『権利関係が確認できない画像なので、差し替えをおすすめします』って、三回」

**両津**「三回も言われとるじゃないか!」

**麗子**「読んでなかったのね……」

**両津**「読まん! 長いんだよあいつの説明は!!」

背後に、いつの間にか**大原部長**。日本刀。無言。

**両津**「ぶ、部長……あの、これはですね、AIというものはですね……」

**大原**「両津ぅぅぅーーーー!!」

**両津**「うわあああああああ!!」

夕暮れの亀有公園を、全力で逃げる両津。追う部長。

**麗子**(見送りながら)「結局、いつもと同じ結末ね」

**中川**「でも先輩、逃げながら何か叫んでますよ」

遠くから両津の声。

**両津の声**「おいAI! **逃走経路の最適化**だぁぁぁ!」

> 「まず立ち止まって、事情を説明することをおすすめします。」

**両津の声**「使えねぇーーーーっ!!」

### 作者メモ(構成のねらい)

- **導入**:中川が善意で新技術を持ち込む → 両さんが金の匂いを嗅ぎつける、という王道の入り
- **膨張**:商店街での荒稼ぎ → 並列実行で規模を欲張る → コストが爆発、というエスカレーション
- **ギャグの軸**:AIが毎回きちんと忠告しているのに、両さんが一切読まないこと。オチまで一貫させる
- **落とし前**:一度は当たる(バズる)が、手抜きの部分が原因で全部消える。両さんは何も学ばない
